SW TL Updater - publishing updates (for ronata)               tool: swtlpublish.exe
==============================================================================
How online updates work
  Players have SWTLUpdater.exe + a small SWTLUpdater.ini with an update address, a public key and (optional)
  a separate translation address. When they start the program (or press 7) it downloads manifest.json +
  manifest.json.sig from each address, checks the signature with the public key, then downloads only the files
  that differ and checks every file's size and SHA-256 against the signed list. Nothing is installed unless
  everything checks out. Only SWTLUpdater.exe, README.txt, Tools\ and TL csv\ are ever touched.
  - PROGRAM repo (UpdateURL):   SWTLUpdater.exe + README.txt
  - TRANSLATION repo (TranslationURL): TL csv\ only. The program refuses anything else from it.
  Both repos are signed with the same key. Tools are NOT published anywhere.

Why PUBLIC repos?  A private repo needs a token, and a token inside a program that many people download can be
  extracted. Keep your private work private and publish only the finished files. The signature means that even a
  hacked host cannot push anything players' programs would accept.

One-time setup
  1. Key (once!):  swtlpublish keygen -out keys   -> keep keys\swtl_update_PRIVATE.key secret and BACKED UP.
  2. Two public GitHub repos (program + translation), each cloned in GitHub Desktop.
     Each needs a .gitattributes file with:   * -text   (otherwise git rewrites the CSV line endings and the
     checksums stop matching).
  3. release_config.bat: set TLURL to the translation repo's raw address (with trailing slash).
  Limits: 100 MB per file on GitHub; use GitHub Desktop or git to push (the web uploader stops at 25 MB per file).
  raw.githubusercontent.com can take a few minutes to show a new commit.

Every release (three scripts, run from the command prompt in the publishing folder)
  1_release_program.bat 2.8.1 "notes"     new exe/readme -> program repo clone. Then commit + push.
       - Use a HIGHER version every time, and give the exe the same version number (the exe only updates itself
         when the release version is higher than its own).
  2_release_translation.bat "notes"       CSVs -> translation repo clone. Then commit + push. Version is the date/time.
  3_make_player_zip.bat                   the zip for players (exe, readme, CSVs, your Tools folder, settings file).
  If nothing changed the publisher says UNCHANGED and GitHub Desktop shows nothing to push.
  Files removed from a release are deleted on the players' PCs.

Tools are not published (decided)
  7z and the structs dumper (and SWAdmin, only if Converter=swadmin) belong to their authors. They are never put in a repo. 3_make_player_zip
  adds your Tools folder to the zip you hand out yourself - check each author's terms first. Players who get only
  the exe are told which files to put in Tools. The updater never touches files that are not in a release.

Translation files - read DISCLAIMER.md before publishing them
  The CSVs are translations of the game's text, i.e. derived from the owner's copyright, and the game's terms
  restrict modifying game data. No permission has been obtained. Keep the files English-only (no original text),
  non-commercial, no game files, and remove promptly if asked. The separate translation repo means a takedown
  of it does not affect the program.

Players can turn updates off: Settings > Update address > "-" (or UpdateAtStartup=no / empty UpdateURL in the .ini).

Patches for big tables
  The release step also writes small patches for big translation files into a "patches" folder, next to "files".
  A player who has one of the last 10 versions of a file downloads one patch (rows are matched by their ID, so a few
  changed rows are a few KB) instead of the whole file. Everything else falls back to the whole file. The rebuilt file
  must match the signed SHA-256, so a patch cannot install a wrong file. Older program versions ignore patches.
  Old versions used for patches are kept in release\swtl_history on the publisher PC (never uploaded).
