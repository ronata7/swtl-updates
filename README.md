# SW TL Updater - update server

Update files for **SW TL Updater**, an unofficial tool that applies a community English translation to your own copy of SoulWorker's data tables.

> Unofficial fan project, not affiliated with the game's developers or publishers. See [DISCLAIMER.md](DISCLAIMER.md).

## For players
1. Download the program zip (see **Releases**) and unzip it anywhere.
2. Put the tools it asks for into a `Tools` folder (they are not included - they belong to their authors; the program tells you exactly which and where to get them).
3. Start `SWTLUpdater.exe`, pick your game folder and press **1) Patch now**.

The program checks this repository for new versions of itself and the translation when it starts. Every download is verified against a digital signature, so only the publisher can issue updates. You can turn it off in *Settings > Update address*.

## For the publisher
See [docs/PUBLISHING.txt](docs/PUBLISHING.txt). The files `manifest.json`, `manifest.json.sig` and the `files/` folder in the root of this repository are generated by `swtlpublish` - do not edit them by hand.
